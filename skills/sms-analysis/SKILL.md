# 短信数据分析

## 使用条件

用户询问以下内容时使用：

- 短信发送量
- 短信成功率
- 短信回执
- 敏感词拦截
- 短信平台异常
- 通道或平台指标对比

## 执行步骤

1. 确认查询的开始日期和结束日期。
2. 使用 `query_sms_summary` 查询短信平台数据。
3. 如果查询结果已经包含最终指标，不要重复运行代码。
4. 只有需要重新分组、排序、计算比例或校验总量时，才使用 `run_python`。
5. 检查：
   - 拦截量不得大于提交量。
   - 成功量不得大于提交量。
   - 各平台合计应等于总体数据。
6. 输出：
   - 查询时间范围
   - 总提交量
   - 成功量和成功率
   - 敏感词拦截量和拦截率
   - 异常平台
   - 数据来源
   - 计算方式

## 限制

- 不修改短信平台数据。
- 不直接发送邮件。
- 不生成查询结果无法支持的结论。
